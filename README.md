## Installation

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm 

### Steps

1. **Clone the repository**

   ```bash
   git clone https://github.com/lembas-cracker/max-chat.git
   cd max-chat
   
2. **Install dependencies**

   ```bash
   npm install
   
3. **Start the development server**

   ```bash
   npm run dev
